# 决赛技术真实性与一致性核查说明

本材料整理日期：2026-09-20。代码仓库：[GOAI-Champ](https://github.com/Liuxiang-hub/GOAI-Champ)。

## 提交内容与技术范围

本仓库提供 HUST_HRT 基于 Pi0.5 的双 PIPER-X 部署覆盖代码，包括机器人端适配、RTC 异步调度、模型内 VJP/PiGDM 引导、安全执行以及测试工具。它依赖外部 XPolicyLab/OpenPI 工程，不是完整独立发行包。

机器人接收三路图像、14维关节及夹爪状态和任务指令，模型生成50步动作；客户端按25Hz执行，后台计算下一块。旧动作经状态重对齐和检查点输入变换后用于模型内引导，响应按实际已执行步数对齐。请求代际校验与引导预热用于处理过期响应及首次编译。

## 现场一致性口径

现有材料包含2026-09-20现场代码快照及后续模型内RTC覆盖文件。当前源码包含引导实现，但历史回放记录没有明确绑定该实现的提交号，不能将其直接作为最新版模型内引导有效性的证据。

公开默认配置关闭硬件输出，现场快照包含启用硬件输出的配置；两者有意不同。最终核查须记录实际加载的源码路径、完整提交号、配置哈希、模型检查点、归一化统计和关节映射。历史哈希不能替代当前现场核验。
