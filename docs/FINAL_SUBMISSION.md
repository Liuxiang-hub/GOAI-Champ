# 决赛技术真实性与一致性核查说明

本材料整理日期：2026-09-20。代码仓库：[GOAI-Champ](https://github.com/Liuxiang-hub/GOAI-Champ)。

## 提交内容与技术范围

本仓库提供 HUST_HRT 基于 Pi0.5 的双 PIPER-X 部署覆盖代码，包括三路视觉与双臂状态适配、同步前缀执行、关节与夹爪动作转换，以及评测和回放工具。它依赖外部 XPolicyLab/OpenPI 工程，不是完整独立发行包。

机器人接收三路图像、14维关节及夹爪状态和任务指令，模型生成50步动作；客户端以25Hz名义频率执行前15步，再更新观测并请求下一块。执行前缀长度控制重新观测与预测的节奏。仓库另保留RTC异步调度和模型内VJP/PiGDM引导作为实验功能，其真机性能收益尚未得到确认。

## 现场一致性口径

2026-09-20只读核查确认现场HRT执行循环从motion_gate.json读取synchronous_prefix模式，控制频率25Hz、执行前缀15步。本轮将公开默认模式与该方案对齐。历史快照和实验覆盖文件另行保留，不代表当前现场配置或已验证性能指标。

公开默认配置关闭硬件输出，现场快照包含启用硬件输出的配置；两者有意不同。最终核查须记录实际加载的源码路径、完整提交号、配置哈希、模型检查点、归一化统计和关节映射。历史哈希不能替代当前现场核验。
