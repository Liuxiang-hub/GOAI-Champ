# 决赛技术真实性与一致性核查说明

本材料整理日期：2026-09-20。代码仓库：[GOAI-Champ](https://github.com/Liuxiang-hub/GOAI-Champ)。

## 提交内容与技术范围

本仓库提供 HUST_HRT 基于 Pi0.5 的双 PIPER-X 部署覆盖代码，包括三路视觉与双臂状态适配、同步前缀执行、关节与夹爪动作转换，以及评测和回放工具。它依赖外部 XPolicyLab/OpenPI 工程，不是完整独立发行包。

机器人接收三路图像、14维关节及夹爪状态和任务指令，模型生成50步动作；客户端以25Hz名义频率执行前15步，再更新观测并请求下一块。执行前缀长度控制重新观测与预测的节奏。

## 现场一致性口径

2026-09-20现场核查确认HRT执行循环从motion_gate.json读取synchronous_prefix模式，控制频率25Hz、执行前缀15步。公开默认模式与该方案一致。历史快照另行归档，不参与当前运行。

公开默认配置关闭硬件输出，现场运行配置按受控流程启用硬件输出；两者有意不同。模型检查点、归一化统计和关节映射由部署配置共同约束。

## 已有实现与验证边界

- 现场方案：Pi0.5动作预测、三相机与双臂适配、同步前缀执行。
- 真机记录：现场日志记录了多项任务的HDF5和视频保存，最近核查到fill_pen_holder第30条episode于2026-09-20 18:06完成保存；保存记录不等于任务成功判定。
- 归档材料：历史实验代码和回放工具保留用于版本追溯，不属于当前部署流程。
- 核查方式：配置、代码和日志分别记录运行参数、实现版本与数据产物。
