# 2026-09-21 finals-v1 deployment snapshot

## Scope

This snapshot records the first finals deployment after moving the HRT1 policy
adapter from the field computer to L20. The hardware execution loop remains on
the field computer. Model weights, official recordings, logs, credentials and
private keys are intentionally excluded.

## Active architecture

```text
official eval-runner and robot execution loop (field)
  -> WebSocket public port 6000
  -> HRT1 adapter on L20 localhost:16010
  -> Pi0.5 inference on L20 localhost:6199
  -> pi05-goai6-piper/10000
```

The previous field adapter and reverse tunnel remain available as a rollback
route through L20 localhost port 16000. They are not the active public route in
this snapshot.

## Recorded verification

- L20-local recorded observation returned `20 x 14`, all finite, in 125.531 ms.
- Field-to-public recorded observation returned `20 x 14`, all finite, in
  181.624 ms.
- A 61-request official run measured model inference P50/P95/P99 of
  108.168/108.524/108.731 ms.
- The same run measured L20 adapter internal P50/P95/P99 of
  110.887/111.282/111.496 ms.
- A later 1670-step recording showed a 45.020 ms median action interval
  (approximately 22.2 Hz actual) and a 189.947 ms median chunk-boundary gap.

These measurements verify protocol flow and timing. They do not establish task
success rate or physical task completion.

`HRT1` is the policy name and deployment adapter used by this Pi0.5 route; it
is not the archived LingBot stack. The files under `archive/` are not part of
this deployment.

## Rollback

Only switch while the official runner is idle and no recording file is open:

```bash
systemctl disable --now hrt1-l20-public.socket
systemctl stop hrt1-l20-public.service
systemctl enable --now hrt1-field-public.socket
```

To return to the L20 route, stop and disable the field public socket, then
enable and start `hrt1-l20-public.socket`.
